# Notes

Personal study notes on continuum mechanics and fracture mechanics, written as web pages with rendered equations and interactive visuals.

## Read the notes online

**https://arka12321.github.io/notes/**

The home page lists all notes. Each note opens in a new browser tab.

## Contents

- [Linear isotropic stress–strain relation](https://arka12321.github.io/notes/stress_field_3d.html): derived from elastic energy and from symmetry alone
- [Why K controls the crack tip](https://arka12321.github.io/notes/k_dominance.html): K-dominance, similitude and small-scale yielding (Fracture Mechanics, Ch. 2)

## Run locally

Open `index.html` in a browser. An internet connection is needed for the equations (MathJax) and fonts to load.
